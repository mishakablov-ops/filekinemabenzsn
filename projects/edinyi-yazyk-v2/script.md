# Факты: Вилли Рамирес, Флорида, 1980: семья сказала «intoxicado» (ему плохо, отравился), врачи поняли «передозировка»,
# а у 18-летнего было внутримозговое кровоизлияние; паралич, выплата 71 млн $ (Price & Reutter, Health Affairs).
# Гуугу-йимитирр (Хоупвейл, Квинсленд): для направлений не используют «лево/право», только стороны света (Levinson; Deutscher, NYT 2010).
# Японское 木漏れ日 «комореби» — солнечный свет сквозь листву деревьев.
