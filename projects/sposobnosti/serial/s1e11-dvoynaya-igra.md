# Серия 11 · «Двойная игра» (~70 с, экшен)

**Логлайн:** Ася играла роль ради брата. Орлова хочет усилить радиус героя и выключить силы во всей стране, кроме
Службы. Команда забирает брата, но, уходя, герой гасит силы сорока телекинетиков, и башня начинает падать. Чтобы её
удержать, он бежит от выхода, а не к нему.
**Новые:** Тимофей (брат Аси, 7 лет), план Орловой.
**Клиффхэнгер:** Тимофей: «Я тебя помню. Ты тот, кто загадал».

## Текст

```
# --- 1. Хук
%slam Ася остановила ==время.==
У нас было // десять [секунд.]

# --- 2. Правда
«Орлова держит здесь // моего ==брата.==
Я играю, // что я с ней.
Ей нужен ты. // Твой радиус [растёт.]
Если его ==усилить,== // силы погаснут // во всей стране.
Кроме тех, // кто в ==Службе.==»

# --- 3. Тимофей
Время пошло.
Мы нашли брата. // Тимофею ==семь.==
И побежали к [выходу.]

# --- 4. Падение
Но с каждым моим шагом // вниз
сорок телекинетиков // ==слабели.==
Башня ==накренилась.==
И я развернулся. // И побежал // [от выхода.]
Наверх. // Как можно ==дальше== от них.
Денис выносил людей. // Последним меня вытащила ==Ася.==
В остановленном *времени.*

# --- 5. Клиффхэнгер
Тимофей взял меня // за руку.
И сказал:
«Я тебя помню. // Ты тот, ==кто загадал.==»
Следующая серия // уже в ==профиле.==
```
