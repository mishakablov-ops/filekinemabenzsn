# Серия 4 · «Первая» (~60 с)

**Логлайн:** девочка, которая остановила время, — Ася. Она объясняет: силы были у людей и раньше, таких зовут Первыми,
и на Первых чужие силы не действуют. Герой, по её словам, тоже Первый.
**Новые:** Ася, Служба равновесия по имени, пропавший брат Аси.
**Клиффхэнгер:** сообщение от Службы «Отойди от неё. Она опасна» и дрон в окне.

## Текст

```
# --- 1. Хук
%slam Время ==стояло.==
А мы с ней // шли по застывшей [столовой.]

# --- 2. Ася
Её зовут Ася. // Она останавливает ==время.==
На десять секунд. // Потом ей нужно [отдышаться.]
Я спросил: // «Почему ты двигаешься рядом со мной?»
Она сказала: // «Потому что я была ==до той ночи.==»

# --- 3. Первые
Оказалось, силы у людей // были и ==раньше.==
Тайно. // У очень [немногих.]
Их называют ==Первыми.==
Силы Первых // друг на друга ~~не действуют.~~
«Поэтому ты меня не гасишь. // А я тебя не ==замораживаю.==
Ты тоже Первый. // Просто *не помнишь.*»

# --- 4. Брат
Год назад // у Аси пропал [брат.]
Его увели // люди в ==форме.==
Те самые, // что пришли за мной // в шесть утра.
Служба ==равновесия.==

# --- 5. Клиффхэнгер
Время пошло. // Сок плеснул на ==пол.==
А мне пришло сообщение // с неизвестного номера:
«Отойди от неё. // Она ==опасна.==»
Подпись: [Служба.]
А в окне // висел ==дрон.==
Следующая серия // уже в ==профиле.==
```
