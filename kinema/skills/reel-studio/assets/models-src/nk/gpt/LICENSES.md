# Происхождение и лицензии

Все включённые меши и растровые карты созданы для этого задания программным
построением геометрии и рисованием собственных текстур. Скачанных моделей,
текстур, HDRI, звуков, сканов, моделей из игр и image-to-3D результатов в архиве нет.

Созданные для набора геометрия, растровые карты и превью предоставляются с
посвящением CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/
Можно использовать и изменять в коммерческой работе без указания авторства.

## Инструменты проверки, не включённые в архив как сторонние ассеты

- Blender 4.5.9: https://download.blender.org/release/Blender4.5/ — дистрибутив проверен по опубликованному SHA-256.
- Khronos glTF Validator 2.0.0-dev.3.10: https://github.com/KhronosGroup/glTF-Validator
- three.js r180, GLTFLoader, RoomEnvironment: https://github.com/mrdoob/three.js
  RoomEnvironment использован только для освещения контрольного просмотрщика;
  сгенерированная им environment map не включена в .blend или .glb.
