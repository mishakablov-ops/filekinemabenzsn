# Канал без лица (`kanal-bez-lica`)

- **Стиль:** блендер (полный), герой `hero_rig.blend`
- **Длительность:** ~35 с · **Голос:** Gemini «Algenib»
- **Статус:** сценарий v1.2 принят; кадры на согласовании, полный рендер только после «да» mike (24.11.2026)
- **Жанр:** рекламный ролик воронки, «реклама денег, а не история» (mike 24.11). Правила: `knowledge/rules/promo-funnel.md`.
- **ЦА:** безликие каналы и новички, которые не разбираются в нейросетях → тариф «Настроим за тебя» (6 000 ₽).
- **Факты:** сумм заработка нет, доход не обещаем. Уведомления о рекламе на экране без цифр.

## Концовка

Кодовое слово **«канал»**, между делом: «Кто напишет в комментах "канал", расскажу, с чего начать». На экране маленькая
подпись у значка комментариев, без капса. Ответ в личку: `t.me/aipollonvideo_bot?start=kanal`. Карточка «поддержи
лайком и подпиской» в теме «монеты».

## Сцена (`blender/`)

- `build_pc.py -- --shot k01 --still DIR` — кадр; `--mp4 FILE` — план целиком (только после одобрения mike).
- Экраны (PNG) берутся из `KANAL_UI`, `ui/` рядом или `/mnt/project-files/aipollon/kanal-bez-lica/ui/`.
- Телефон 11 × 23 см под чиби-кисти; держит двумя руками, кулаки за корпусом, экран не закрывают.
- Планы с экраном телефона (`k01`, `k03`, `k09`) — камера на нормали экрана со стороны лица, верх кадра = верх экрана;
  `clip_start` отсекает лицо героя между камерой и телефоном. Взгляд из самих глаз не годится: чиби-кулаки закрывают экран.
- Ночь (`k04`): своё освещение (монитор, лампа), `fill` 0.04, экспозиция 0.1.
- За окном «Метрополис» (mike 25.11: «поменяй на улице вид на наш город новый»): `city_view()` переносит комнату,
  героя, камеру и свет на 8-й этаж над набережной (`CITY_AT` = (0, 18, 24)), окно смотрит вдоль проспекта x = 0 в
  Даунтаун; ночью пресет `night` (горят окна, фонари, поток фар). Сборка сцены дольше на ~10 с.

**Звук:** без музыки, mike сам кладёт house music. Отдавать готовый MP4 (голос + звуки) и отдельно дорожку голоса и звуков WAV, чтобы ему было удобно сводить.
