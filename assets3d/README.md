# assets3d — 3D-модели файлами

Здесь хранятся модели **файлами** (glb/gltf/fbx/obj/blend), небо HDRI и текстуры, которые Claude добавляет по ходу работы.
Модели **из кода** (Python для Blender) лежат не здесь, а в [`blender/library/`](../blender/library/).
Модели, которые движок KINEMA грузит в three.js (MacBook, iPhone 17, руки FPS, Poly Haven), — в
`kinema/skills/reel-studio/engine/public/models/`; если модель нужна обоим путям, оригинал здесь, копия там.

## Структура

```
assets3d/
  <категория>/<источник>/<имя-модели>/   файлы одной модели (+ превью preview.jpg по возможности)
  manifest.csv                            одна строка на каждую модель
  _tools/download_assets.ps1              скачивание паков на ПК (Kenney, Quaternius, Poly Haven, ambientCG)
```

Категории: `people/` (люди, персонажи, анимации), `vehicles/` (машины, транспорт), `city/` (здания, дороги, уличные
мелочи), `nature/` (деревья, камни, трава), `interior/` (мебель, техника, еда), `animals/`, `props/` (прочие предметы),
`hdri/` (небо), `textures/` (PBR-материалы). Источник: `kenney/`, `quaternius/`, `polyhaven/`, `ambientcg/`,
`sketchfab/`, `own/` (сделано нами, например персонаж по описанию через `blend2glb.py`).

## Правила

1. **Лицензия:** только CC0 или CC-BY (с автором в манифесте и в описании ролика, если модель видна).
2. **Манифест обязателен:** `category,source,name,path,license,author,url,added,used_in,notes`.
3. **Размер:** файл до ~50 МБ (лимит GitHub — 100 МБ). Тяжелее — уменьшить (текстуры 1k, decimate) или оставить на ПК и
   записать в манифест `path` на ПК с пометкой `local-only`.
4. **Стиль «Блендер / Классика»** по договорённости 22.10.2026 использует модели только из кода. Скачанные модели в
   нём не применять без прямой просьбы пользователя; в «Гибриде» и реалистичных роликах (Poly Haven) — можно.
5. Наборы, которые пробовали и отклонили 22.10.2026 (стили 2–6), — в `_archive/style-tests-2026-10-22/`.
