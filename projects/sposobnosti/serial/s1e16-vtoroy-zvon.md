# Серия 16 · «Второй звон» (~70 с, финал сезона)

**Логлайн:** после второго звона у всех людей по две силы. В школе герою хлопают, Денис занимает ему место,
Ася ждёт у окна. А кружка, на которую он смотрел в серии 1, вдруг сдвигается: у него впервые своя сила.
Смотритель объясняет: в лаборатории было два объекта. Ноль-один отдал свои силы. Ноль-два научился загадывать.
**Клиффхэнгер сезона:** где-то есть ещё один такой же, как он, только он ничего не отдаёт.

## Текст

```
# --- 1. Хук
%slam Небо ==зазвенело.==
Во второй [раз.]

# --- 2. Утро
Утром мир проснулся // с ==двумя== силами.
Бабушка поднимает машины // и теперь ещё [светится.]
Сосед летает // и ==поёт== как оперный певец.

# --- 3. Школа
В школе мне // ==хлопали.==
Денис занял мне место.
Ася ждала // у [окна.]

# --- 4. Кружка
На перемене // я снова смотрел // на кружку.
Как в самый // первый [день.]
И она // ==сдвинулась.==

# --- 5. Ноль-два
«Это не ты, — // сказал Смотритель. —
В лаборатории было // два объекта.
Ноль-один // и ==Ноль-два.==
Ты свои силы // [отдал.]
А второй // научился ==загадывать.==»

# --- 6. Финал
Восемь миллиардов // суперлюдей.
И где-то // ещё один ==такой же,== как я.
Только он // ничего не [отдаёт.]
Если история зацепила, // оставь лайк и ==подпишись.==
Для меня это // настоящая ==суперсила.==
```
