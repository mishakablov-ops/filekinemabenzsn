# Рекламные ролики и воронка (с 20.11.2026)

Правила для роликов, которые ведут людей в бота @aipollonvideo_bot (код бота: `Wpresser/AIpollon-bot`, тексты в
`src/funnel.js`). Обычные ролики канала (истории, «что если…», юмор) живут по `knowledge/aipollon-knowledge.md`.

## Кому продаём

- **20.11 (mike):** в основном владельцы безликих каналов и фрилансеры: делают ИИ-видео и вешают туда рекламу
  (баннеры, интеграции).
- **24.11 (mike):** новая ЦА — люди, которые **не разбираются в нейросетях**. Для них тариф «Настроим за тебя»:
  6 000 ₽ за всё (движок KINEMA + настройка по созвону + первый ролик вместе).

## Подходы (все, что согласованы)

| дата | подход | как применять |
|---|---|---|
| 20.11 | продаём **результат** (деньги, просмотры, клиенты), а не движок | в ролике не «папка в Claude Code», а канал, реклама, просмотры |
| 20.11 | три выгоды: **время**, **объём**, **уникальность** | «ролик из одной фразы», «один вечер — ролики на месяц», «3D выделяется в ленте, а не очередная нейрошляпа» |
| 20.11 | угол «быстрые деньги без усилий» → говорим **«легко и быстро»** | цифры только честные, **доход не обещаем**, суммы заработка не рисуем |
| 20.11 | площадки: TikTok, Instagram, YouTube Shorts | у каждой своя метка `?start=tiktok|insta|yt` |
| 20.11 | **кодовое слово в комментах** → mike пишет в личку → бот | в конце ролика; ответ в личку `t.me/aipollonvideo_bot?start=<метка>`, метка видна в `/sources` |
| 20.11 | пара смешных роликов для прогрева аккаунта | обычные юмор-ролики канала, без рекламы |
| 24.11 | «байт на комменты» во всех новых рекламных роликах | слово под тему ролика |
| 24.11 | текст **не навязчивый** («только текст не делай супер навязчивым») | слово в комменты — между делом, без «Хочешь так же?», без капса; на экране маленькая подпись |
| 24.11 | ролик **как реклама денег, а не как история** («сделай ролик не как историю, а как рекламу денег») | структура: хук про заработок без лица → откуда деньги (реклама, интеграции) → что мешает (роликов нужно много) → KINEMA → «не шаришь — настроим» → слово в комменты |
| 24.11 | подарка «10 тем» нет, Replicate покупателю не нужен | не обещать подарок за слово; голос — любой сервис, есть бесплатные |

## Чего не делать

- Не обещать доход и не показывать выдуманные суммы на экране (уведомления о рекламе — без цифр).
- Не продавать «в лоб» по ходу ролика: реклама — это сама история выгоды, призыв один, в конце.
- Не писать язык технаря (движок, архив, Claude Code) — для ЦА это «ИИ делает ролик из одной фразы».
