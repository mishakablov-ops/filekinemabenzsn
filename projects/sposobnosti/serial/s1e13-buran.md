# Серия 13 · «Буран» (~70 с, экшен)

**Логлайн:** Буран бьёт по городу молниями и градом с высоты, где радиус героя не достаёт. Команда придумывает:
Ася останавливает время, Денис швыряет героя в небо. В бурю влетает обычный мальчик, и оба падают без сил.
**Клиффхэнгер:** Буран говорит, что сегодня в 03:17 Орлова включает «Тишину». Дома пусто, мамы нет, записка: «Приходи».

## Текст

```
# --- 1. Хук
%slam Град размером // с ==кулак.==

# --- 2. Атака
Буран висел в небе // в сотне метров от [меня.]
Мои семь метров // там ~~не работали.~~
Молнии // били по ==крышам.==
А каждая молния // в пять раз горячее // поверхности ==Солнца.==

# --- 3. План
«Не можешь подойти — // ==долети,==» — сказал Денис.
Он привязал меня // к тросу длиной // восемь [метров.]
На метр дальше // моего круга.
Раскрутил, // как молот, // и ==швырнул== в небо.

# --- 4. Полёт
Я летел // прямо в [бурю.]
Двадцать метров. // Десять. // ==Пять.==
Буран // ==погас.==
И мы оба // полетели [вниз.]

# --- 5. Спасение
Ася снова остановила время. // У самой ==земли.==
Денис поймал нас // в последний [момент.]

# --- 6. Клиффхэнгер
Буран засмеялся:
«Думаешь, // я главная проблема?
Сегодня в три семнадцать // Орлова включает ==Тишину.==»
А дома было [пусто.]
На столе — // мамин телефон. // И записка:
«==Приходи.==»
Следующая серия // уже в ==профиле.==
```

> Почему у Дениса работает сила: трос 8 м, а круг героя 7 м, Денис всё время на метр дальше. Это показать сверху
> кольцом и титром, тогда зритель поймёт без объяснений.
