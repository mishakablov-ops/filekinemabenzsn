# Факты и ссылки: README.md проекта (ООН, Вейсман, Falchi 2016, USDA, AAA, Deryabina 2015).

# --- 1. Хук
%slam Ты просыпаешься. // Людей ==нет.==
Исчезли все // =={8|восемь} миллиардов.==
Остался один человек. // И это *ты.*

# --- 2. Пустой город
Машины стоят // посреди [дороги.]
В кафе на столе // кофе ещё *тёплый.*
Пишешь маме. // Сообщение ~~не~~ доходит.

# --- 3. Мир выключается
Через несколько часов // гаснет [свет.]
Станциям нужны люди. // А их ==нет.==

# --- 4. Всё твоё
Зато все магазины // теперь [твои.]
Хлеб покроется плесенью // за ==неделю.==
А консервы хранятся // до ==пяти лет.==
Любая машина // тоже *твоя.*
Но бензин портится // за ==полгода.==

# --- 5. Ночь
Ночью ни одного фонаря. // Город [чёрный.]
А над ним // ==Млечный Путь.==
Раньше треть людей // его ~~не~~ видела.

# --- 6. Через год
Через год // в города приходят [волки.]
В зоне Чернобыля их // ==в {7|семь} раз== больше,
чем в *заповедниках.*

# --- 7. Развязка
Ты последний человек // на ==Земле.==
Сидишь в пустой комнате. // [Тишина.]
%slam И вдруг // в дверь ==стучат.==

# --- 8. Подводка
Кстати, // это видео сделала ==нейросеть.==
Хочешь делать такие же // [в два клика?]
Тебе // ==в шапку профиля.==
