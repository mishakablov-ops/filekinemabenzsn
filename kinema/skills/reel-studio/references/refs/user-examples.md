## What to beat (applies to all four)
Static holds of 4–6 s on one layout; captions over busy photos without scrim; the same card style repeated; little camera motion on UI scenes; promo audio bed is barely audible. Reel Studio defaults already address these (scene every 1.2–4 s, scrim, block variety, camera moves, designed SFX).
