# Серия 5 · «Стройка» (~65 с, экшен)

**Логлайн:** Денис с бандой ловит героя после уроков на стройке. Герой понимает правило своей силы и идёт не от них,
а на них. В бою он выбирает спасти детей, а не победить, и Денис впервые его уважает.
**Новые:** Вика (бег), Гоша (огонь); правило «5 метров».
**Клиффхэнгер:** в остановленном времени двигался кто-то третий — мужчина в сером пальто.

## Текст

```
# --- 1. Хук
%slam Денис пришёл // не ==один.==

# --- 2. Засада
После уроков // меня ждали ==трое.==
Денис, // сила десятерых.
Вика. // Бегает быстрее [машины.]
И Гоша, // у которого из ладоней // ==огонь.==

# --- 3. Правило
Тогда я понял правило // моей силы.
Пять метров. // Ближе — вы обычные. // Дальше — [нет.]
Поэтому я не побежал. // Я пошёл ==на них.==

# --- 4. Бой
Вика влетела в мой круг // и ==кувыркнулась.==
Огонь Гоши // погас у моего [лица.]
Денис замахнулся. // Ася остановила ==время.==
И я просто // встал к нему *поближе.*

# --- 5. Балка
Денис швырнул балку. // Она полетела // в сторону ==детской площадки.==
Если я рядом, // он её ~~не удержит.~~
И я [отошёл.]
Денис прыгнул // и поймал её // ==одной рукой.==
Потом долго смотрел на меня. // И *кивнул.*

# --- 6. Клиффхэнгер
Вечером Ася сказала:
«Когда я остановила время, // двигались ==трое.==»
Я, она... // и мужчина в сером [пальто.]
Он стоял на кране // и ==смотрел.==
Следующая серия // уже в ==профиле.==
```
