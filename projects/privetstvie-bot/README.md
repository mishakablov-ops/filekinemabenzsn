# Приветствие для Telegram-бота (`privetstvie-bot`)

- **Что:** короткий бесшовный цикл, где герой канала машет рукой. Это приветствие в боте @aipollonvideo_bot.
- **Герой:** low-poly Аполлон с аватарки и баннера канала (референсы mike 23.11.2026): юноша с белыми кудрями,
  в лавровом венке, в хитоне с драпировкой, бело-золотая палитра, золотые ленты, четырёхлучевые звёзды,
  колонны и летающие кристаллы. Это **не** `hero_rig.blend` (тот герой по фото, в худи).
- **Стиль:** Блендер, сцена целиком из кода (`blender/build.py`), Eevee, 1080×1080, 30 к/с, 4 с (120 кадров), без звука.
- **Статус:** v1 выдан 23.11.2026; 24.11 mike попросил пока убрать его из бота (там выключено строкой `WELCOME_ANIMATION`), отложен.

## Как собрать

```
python3 blender/build.py --still 6 18 --out /tmp/s_#.png --size 720     # проверочные кадры
python3 blender/build.py --frames /tmp/frames --size 1080 --samples 32   # 120 PNG
# Blender 5.x на ПК: blender -b -P blender/build.py -- --frames D:\aipollon\privetstvie-bot\frames
ffmpeg -framerate 30 -i /tmp/frames/f_%03d.png -c:v libx264 -pix_fmt yuv420p -crf 18 -movflags +faststart privetstvie-bot-v1.mp4
```

В облаке рендер идёт через `pip install bpy` (5.3): Cycles CPU 24 сэмпла ≈ 17 с/кадр (120 кадров ≈ 35 мин). Eevee тоже работает, но медленнее (≈ 43 с/кадр) на программном Vulkan:
`VK_ICD_FILENAMES=/opt/lavapipe/lvp_icd.json`.

Цикл бесшовный: все движения — синусы с периодом, кратным 120 кадрам. Кристаллы поворачиваются на 90° за цикл,
звёзды на 90°, нимб на 90° (видны 4 звезды из 12), лента вокруг героя на 120°, поэтому кадр 120 совпадает с кадром 0.
Рука: плечо `r_shoulder`, локоть `r_elbow`, кисть `r_wrist`, пять взмахов за цикл. Моргание на кадрах 70–76.
