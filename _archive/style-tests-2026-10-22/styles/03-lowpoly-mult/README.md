# Стиль 3 · Low-poly мульт

Гранёный low-poly Quaternius: видны грани, мягкие природные цвета, человеческие пропорции. Люди с анимациями ходьбы, бега, работы (плюс библиотека анимаций), животные, машины, автобусы и трамваи, корабли, здания, улица со знаками и светофорами, богатая природа (деревья, кусты, поля, пустыня), мебель и интерьер дома, еда. Сюда же подходят мультяшные люди Kenney protagonists/survivors.

Превью: `preview.jpg` в этой папке (если есть).
