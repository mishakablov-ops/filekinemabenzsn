## Рендер на ПК (25.11)

1. `KINEMA_RS=<RS> python -I engine/voice_sections.py` → `<RS>/engine/public/projects/kanal-bez-lica/{voice.wav,words.json}`.
2. `python -I tools/render_clips.py --blender <blender.exe> --rs <RS> [--seq-root DIR] [--pixel-half split_pixel.mp4]` → `tools/build_timeline.py` пишет в `blender/shots.json`
   начала и длины планов и события в плане (уведомления, галочки, палец, набор «канал»), затем 9 планов EEVEE кадрами
   (~2 с на кадр на RTX 3060) → `clips/<план>.mp4`, проверка `clips/_check/sheet.jpg`.
3. `python -I engine/storyboard.py --rs <RS>` → `spec.json` (титры сверху, звуки на событиях, концовка после голоса).
4. `render.py kanal-bez-lica` (TEMP на C:) → QA → `D:\aipollon\output\` MP4 + WAV голоса и звуков.

## Сцена (`blender/`)

- `build_pc.py -- --shot k01 --still DIR` — кадр; `--mp4 FILE` — план целиком (только после одобрения mike).
- Экраны (PNG) берутся из `KANAL_UI`, `ui/` рядом или `/mnt/project-files/aipollon/kanal-bez-lica/ui/`.
- Телефон 11 × 23 см под чиби-кисти; держит двумя руками, кулаки за корпусом, экран не закрывают.
- Планы с экраном телефона (`k01`, `k03`, `k09`) — камера на нормали экрана со стороны лица, верх кадра = верх экрана,
  телефон ниже центра (сверху место для титров). Голова героя прозрачна только для камеры (`hide_head_for_camera`, по группе
  вершин `Head`); `clip_start` для этого не годится: резал кулаки, в EEVEE они становились белыми «крыльями» (25.11).
  Взгляд из самих глаз не годится: чиби-кулаки закрывают экран.
- Ночь (`k04`): своё освещение (монитор, лампа), `fill` 0.04, экспозиция 0.1.
- За окном «Метрополис» (mike 25.11: «поменяй на улице вид на наш город новый»): `city_view()` переносит комнату,
  героя, камеру и свет на 8-й этаж над набережной (`CITY_AT` = (0, 18, 24)), окно смотрит вдоль проспекта x = 0 в
  Даунтаун; ночью пресет `night` (горят окна, фонари, поток фар). Сборка сцены дольше на ~10 с.

**Звук:** без музыки, mike сам кладёт house music. Отдавать готовый MP4 (голос + звуки) и отдельно дорожку голоса и звуков WAV, чтобы ему было удобно сводить.
