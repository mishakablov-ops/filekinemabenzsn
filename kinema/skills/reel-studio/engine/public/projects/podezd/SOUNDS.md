# Звуки для примера «Подъезд»

Пример рендерится и без них — движок просто пропустит отсутствующие файлы. Чтобы звучало как в оригинале,
положите свои mp3 в `engine/public/projects/podezd/sfx-src/` с такими именами
(бесплатные звуки: pixabay.com/sound-effects, freesound.org с лицензией CC0 — проверяйте лицензию каждого файла):

| файл | что это |
|---|---|
| `drone.mp3` | низкий тёмный гул, 25+ секунд (фон) |
| `stairwell_tone.mp3` | гулкий тон пустого подъезда |
| `lamp_buzz.mp3` | гудение лампы |
| `steps_concrete.mp3` | шаги по бетонной лестнице |
| `pipe_knock.mp3` | стук по трубе стояка |
| `drip.mp3` | капает вода |
| `people_moan.mp3` | тихие стоны людей |
| `child_cry.mp3` | детский плач |
| `woman_scream.mp3` | женский крик |
| `breath_scared.mp3` | испуганное дыхание |
| `door_creak.mp3` | скрип двери |
| `doors_open_close.mp3` | двери открываются и закрываются |
| `furniture_drag.mp3` | тащат мебель |
| `bones_crack.mp3` | хруст костей |
| `pages.mp3` | шелест бумаги |
| `phone_beeps.mp3` | гудки телефона |
| `stinger.mp3` | резкий хоррор-удар (финал) |

Тайминги звуков задаёт `assets/models-src/podezd/storyboard.py` (параметр `from` — с какой секунды файла играть).
Если ваш файл начинается с тишины, поправьте `from` и пересоберите: `python -I storyboard.py`.
