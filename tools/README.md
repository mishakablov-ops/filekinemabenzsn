# Утилиты

- `worker/START_WORKER.bat` + `worker/worker.ps1` — окно-исполнитель на ПК пользователя. Выполняет `.ps1` из
  `jobs/queue/` по порядку имён (`bg_*` — в отдельном свёрнутом окне), логи в `jobs/logs/`, готовые — в `jobs/done/`.
  Пользователь запускает его сам; если ПК уснул, попросить открыть снова. Обходить ограничение облака (нет доступа к
  replicate.com и download.blender.org) запрещено.
- `mcp-blender/` — официальный MCP-сервер Blender Lab (29.10.2026): скрипт установки портативного Blender 5.2.3 + аддона
  + сервера, пример `.mcp.json`. Только для работы в Blender через Claude Code; ролики рендерятся на Blender 4.5 LTS.
