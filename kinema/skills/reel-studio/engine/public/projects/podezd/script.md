# Подъезд. Хоррор-история от первого лица (~2 мин), часть 1. Голос: Gemini 3.1 Flash TTS · Algenib.
# Рассказывает Дима, жилец хрущёвки. Существо своё (не SCP): высокий, худой, закрывает лицо руками.

# --- 1. Хук
Третью ночь соседи // стоят ==лицом в угол.==
И *воют.*

# --- 2. Дом
Меня зовут Дима. // Хрущёвка, ==четвёртый этаж.==
Лифта нет. // Только лестница,
зелёные стены // и лампочки по {40|сорок} *ватт.*
Внизу вахта. // Там {40|сорок} лет сидит
==Валентина Петровна.==
Она знает всех. // И при мне всегда
*закрывает журнал.*

# --- 3. Первые
Первым был Серёга со второго. // Сидел на ступеньках
и ==держался за голову.==
Я спросил, что случилось. // Он прошептал:
*«Не смотри вниз».*
Через день их было ==трое.== // Каждый в своём углу.
Они не спят. Не едят. // Они ==слушают.==
Ночью в {стояке|стояк+е} — *стук.* // Снизу вверх.
Этаж за ==этажом.==
А лампочки мигают в одном ритме. // Как будто кто-то ==дышит.==

# --- 4. Крик
В ночь на пятницу // меня разбудил ==крик.==
Кричала Валентина Петровна. // Снизу. *Долго.*
Я вышел на площадку. // Соседи повернулись ко мне.
==Все разом.==
И молча показали // [вниз.]

# --- 5. Вахта
Вахта открыта. Стул опрокинут. // Чай ещё ==тёплый.==
Журнал на полу. // На последней странице —
==моя фамилия.==
А за шкафом — дверь, // которой здесь *никогда не было.*
Я позвонил в полицию. // Гудки.
А потом в трубке // ==кто-то заплакал.==

# --- 6. Спуск
Я включил фонарик. // Ступени вели вниз.
==Ниже подвала.==
Связь пропала // на первом же пролёте.
Я считал пролёты. // ==Шесть.== В пятиэтажке.
На стенах — царапины. // На уровне *моего лица.*
Внизу кто-то плакал. // Тихо. Как ==ребёнок.==

# --- 7. Он
Он сидел ко мне спиной. // Очень высокий. Очень ==худой.==
И закрывал лицо // *руками.*
Рядом лежал // ==платок Валентины Петровны.==
Я сделал шаг. // Плач ==оборвался.==
И он начал медленно // [опускать руки.]

# --- 8. Подводка
Продолжение — // смотри в *профиле.*
