# Сценарий v2 «Посчитаем вечера» (26.11.2026)

Голос Algenib, подача «уверенный питч другу» (BASE из `projects/kanal-bez-lica/engine/voice_sections.py`). 73 слова,
~34 с голоса + ~3 с концовки ≈ 37 с. Слово в комменты между делом, без капса.

v2 по mike 26.11: «не называй суммы, можешь также добавить про универсальность, что типо его можно везде
использовать». Рублей нет ни в голосе, ни в титрах, ни на чеках. Считаем **вечера**, а не деньги. Новая выгода —
**везде подходит**: площадки и темы.
