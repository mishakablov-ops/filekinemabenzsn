# Стиль 5 · Ретро-город

Грубоватый ретро-low-poly с пиксельными текстурами, как в играх начала 2000-х: обшарпанные дома, заборы, мусор, граффити, приглушённые цвета. Люди — ретро-персонажи Kenney с анимациями.

Превью: `preview.jpg` в этой папке (если есть).

## Наборы моделей

Файлы лежат в общей библиотеке `assets3d/` и никуда не перемещались. Пути от папки `aipollon claude`:

- `assets3d/city/kenney/retro-urban-kit/`
- `assets3d/people/kenney/animated-characters-retro/`

Небо для любого стиля: `assets3d/hdri/` (urban, sunset, sky).

Лицензия всех ассетов: CC0, указывать автора не обязательно.
