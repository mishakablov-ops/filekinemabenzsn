# Reel Studio — вертикальные ролики силами агента

Агент сам пишет сценарий, озвучивает, раскладывает сцены по словам, собирает 3D, рендерит 1080×1920 / 60 fps и проверяет результат.
Форматы: **объяснялка с голосом**, **история от первого лица**, **промо под музыку**.

## Первый запуск
```
python scripts/setup.py           # мастер: ключи (скрыто), профиль канала, свой пак звуков
python scripts/setup.py --check   # что подключено, чего не хватает
```
Python окружения: `.venv/Scripts/python` (Windows) или `.venv/bin/python` (macOS/Linux).

## Как пользоваться
Пишите в Claude Code: «сделай ролик про …» / «историю от первого лица про …» / «промо под музыку для …» / «разбери этот ролик и сделай так же».
Агент пройдёт шаги из `SKILL.md`: факты → сценарий (линтер) → голос с пословными таймингами → раскадровка → проверка кадров → рендер → QA-отчёт.

Ручные команды (из папки скилла, `PY` = python окружения):
```
PY -I scripts/new_project.py my-reel --style dusk --music lofi-warm   # заготовка проекта
PY -I scripts/script_lint.py engine/public/projects/my-reel            # проверка сценария
PY -I scripts/tts.py engine/public/projects/my-reel --engine replicate --model gemini --voice Algenib --tighten 0.25
PY -I scripts/sfx_library.py import папка_или.zip                      # подключить свой пак звуков
PY -I scripts/render.py my-reel                                        # рендер + мастеринг −14 LUFS + QA
cd engine && npx remotion studio src/index.ts                          # живой редактор
```

## Что внутри
- 90+ блоков анимации (каталог: `references/blocks.md`), 13 стилей, по умолчанию тёмная тёплая пастель `dusk`
- 3D: MacBook и iPhone 17 Pro с живыми экранами, комнаты (офис, гостиная, спальня, кофейня, студия, библиотека, кухня, домик с камином, подвал-убежище), улица, город, глобус, горы, ядерный взрыв; камера от первого лица; герой в белой кепке
- Голос: Gemini 3.1 · Algenib (Replicate), Fish Audio, ElevenLabs, своя запись, бесплатный Edge
- Звук: пак интерфейсных звуков, кинематографичные удары, 8 музыкальных подложек с сеткой битов
- Финальная заставка: айфон разворачивается к профилю канала (`engine/src/brand.json`)
- QA: наложения, 3D-коллизии, камера внутри объектов, склейки короче 1 с, громкость, тишина, чёрные кадры

## Папки
- `engine/` — движок (Remotion + three.js); `engine/public/` — звуки, музыка, модели, бренд, проекты; `engine/out/` — готовые ролики и отчёты
- `scripts/` — Python-инструменты; `references/` — справочники агента; `examples/` — проекты с исходниками
- `.secrets.env` — ваши ключи (создаёт мастер; никому не отправляйте)
