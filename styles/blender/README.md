## Картинка

- Модели только из кода (`blender/lib.py`, `blender/sets/*.py`): простые матовые формы, никаких скачанных паков
  (`assets3d/` удалён по просьбе пользователя, не предлагать без прямой просьбы).
- **Светлые сцены, минимум теней**: `lib.camera_fill()`, экспозиция +0.35…0.6, туман только мешем `lib.fog_box`.
  Атмосфера через тёплое вечернее небо, контровой свет и дымку, а не темноту.
- Город, а не одна улица: сетка кварталов, площадь с кафе, бульвар, ориентир (пример `fr-klassika/blender/sets/paris.py`).
- Улицы живые, но не перегруженные: машины, люди (`people2.py`: колени, ботинки, кисти, волосы, шаг без проскальзывания,
  сидячие в кафе), фонари, бытовые мелочи. На фоне признаки цивилизации (`civ.py`).
- Люди и конфликты стилизованно, без крови.
- Камера: двумя ключами на сцену (частые ключи дают рывки), объектив около 44 мм, когда нужен «1x»,
  `clip_start` ≥ 0.1 (на облётах 1.0). Не класть плоскости одной высоты внахлёст.

## Титры, голос, звук, концовка

Как в Reel Studio по умолчанию: editorial-титры сверху пословно, голос Gemini «Algenib», свои звуки `sfx_mbg.py`,
`soundtrack.wav` через `mix.py`, концовка `TikTokProfile` (`dark: true`) на `IPhone17`.
Если пользователь просит «оформление как в гибриде», брать разметку титров и звуки из `styles/gibrid/README.md`.

## Два режима рендера

1. **Полный Blender** (по умолчанию для этого стиля): каждая сцена — анимированный клип. ~1–3 с/кадр, минута ролика ≈ 1,5–2 ч.
2. **Быстрый** (раньше назывался «гибридом», пример `fr-test-1b`): из Blender стоп-кадры (`--times … --scale 1.25`)
   с движением камеры в монтаже (`PhotoBG` zoom/pan), анимируются только ключевые «живые» планы. ~15 мин против ~45.
   Предлагать, когда важна скорость.

## Порядок

1. `bash styles/01-klassika/blender-kit/new_blender_project.sh <id>` (или копия `fr-klassika/` для городских сцен с новыми людьми).
2. Факты → сценарий → `script_lint.py` → голос (2 дубля на секцию, Whisper) → `words.json`.
3. `build_timeline.py` → `blender/shots.json` → сцены `blender/sets/<set>.py`.
4. Стоп-кадры `tools/stills.sh` и контактный лист, смотреть самому.
5. Задачи в `jobs/queue/` (пользователь запускает `START_WORKER.bat`), рендер `mkrender.sh`, клипы `-bf 0 -g 30 -keyint_min 30`.
6. `mix.py` → `build_spec.py` → `render.py` → `qa.py` → 20+ кадров из готового MP4.
7. Выдача отдельным файлом с новой версией.
