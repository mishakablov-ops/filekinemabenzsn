# Серия 6 · «Первые» (~60 с)

**Логлайн:** мужчина в сером, Смотритель, приводит героя и Асю в заброшенный планетарий, где прячутся Первые.
Они проверяют его силу: радиус растёт. Служба охотится на Первых, потому что те знают, откуда взялись силы.
**Новые:** Смотритель, Эхо, Ключ, полковник Орлова. Радиус 7 м.
**Клиффхэнгер:** Служба выбивает двери. В капюшоне героя был маячок — их нашли через него.

## Текст

```
# --- 1. Хук
%slam Мужчина в сером // ждал нас // у ==планетария.==

# --- 2. Планетарий
Заброшенный планетарий. // Внутри — ==шестеро.==
Эхо слышит то, что скажут // через три [секунды.]
Ключ открывает // любую ==дверь.==
А мужчину зовут Смотритель. // Он возвращает ==воспоминания.==

# --- 3. Проверка
Они проверили // мою силу.
Пять метров. // Шесть. // ==Семь.==
«Она растёт, — сказал Смотритель. —
Когда тебе страшно, // она [растёт.]»

# --- 4. Служба
Служба ловит ==Первых.==
Потому что Первые знают, // откуда взялись [силы.]
А те, кто знает, // ==исчезают.==

# --- 5. Клиффхэнгер
Вдруг Эхо закричал.
Через три секунды // двери ==вылетели.==
В дыму стояла женщина в форме. // Полковник [Орлова.]
«Спасибо, что привёл нас, // ==Ноль.==»
В моём капюшоне // мигал ==маячок.==
Следующая серия // уже в ==профиле.==
```
