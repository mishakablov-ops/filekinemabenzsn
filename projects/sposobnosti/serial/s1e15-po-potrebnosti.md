# Серия 15 · «Каждому по потребности» (~70 с, кульминация)

**Логлайн:** внутри машины герой слышит все 8 миллиардов желаний. Команда прорывается на башню, Денис держит лестницу уже без силы. Орлова
приказывает «выключи всех», а он разворачивает волну: возвращает каждому его силу и забирает только её «приказ». Буран, получив силу назад, сдувает охрану.
Машина сгорает вместе с его радиусом: теперь он по-настоящему обычный. Мама рядом.
**Клиффхэнгер:** через неделю в 03:17 небо звенит снова.

## Текст

```
# --- 1. Хук
%slam Я слышал ==всех.==
Восемь миллиардов // [желаний.]

# --- 2. Внутри
Через машину // я чувствовал // каждую ==силу.==
Ту, что спасает. // И ту, что [ранит.]

# --- 3. Бой
Охрана Орловой // бросилась к ==креслу.==
Денис держал лестницу. // Без всякой [силы.]
Ася держала ==время.==

# --- 4. Выбор
Орлова приказала: // «==Выключи всех.==»
А я развернул // [волну.]
И вернул каждому // его ==силу.==
А у Орловой // забрал её *приказ.*
Над башней // закрутилась [буря.]
Буран вернулся. // На ==нашу сторону.==

# --- 5. Цена
Машина сгорела. // А вместе с ней // мой ==круг.==
Теперь я по-настоящему // [обычный.]
И мама обняла меня // у подножия ==башни.==

# --- 6. Клиффхэнгер
Неделю // всё было [спокойно.]
А потом, // в три семнадцать,
небо // снова ==зазвенело.==
Следующая серия // уже в ==профиле.==
```
