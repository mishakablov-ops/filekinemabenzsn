# --- 1. Хук
Как познакомиться с ==девушкой?== // Витёк прочитал [сорок гайдов.] // Сейчас он покажет, *как не надо.*

# --- 2. Подкат, кафе
Способ первый — ==подкат.== // Витёк в кафе: // «Ты случайно не вай-фай? // Чувствую [связь».]
Лиза: «Пароль: *нет».* // И пересаживается.

# --- 3. Загадочность, ночная улица
Способ второй — ==загадочность.== // Тёмные очки, // фонарь, // ночь. // Витёк стоит [три часа.]
Подошла только бабушка: // *«Сынок, ты потерялся?»*

# --- 4. Сила, остановка
Способ третий — ==показать силу.== // Сто отжиманий // прямо на остановке.
На сорок втором // Лиза [уехала на такси.] // Досчитал до ста. // *Голуби впечатлены.*

# --- 5. Переписка
Способ четвёртый — ==написать.== // «Привет» — стёр. // «Хай» — стёр.
Через [три часа] отправил: // *«Ты ела?»* // Лиза: «Да». // Диалог окончен.

# --- 6. Цветы
Способ пятый — ==цветы.== // Нарвал их [на клумбе у мэрии.] // Свидание состоялось. // *С полицейским.*

# --- 7. Поворот, парк
Витёк сдался // и сел на лавку. // Лиза садится рядом: // «Ты же тот, кто ==лизнул столб?»==
«Ну... да». // И они [проболтали два часа.] // *Без единого подката.*

# --- 8. Итог
Так как знакомиться? // ==Просто скажи «привет».== // Без подкатов, // без очков ночью, // без [клумбы мэрии.]
Смелость и улыбка — // *вот и весь гайд.*
