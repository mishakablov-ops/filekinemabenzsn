## Картинка

- Модели только из кода (`blender/lib.py`, `blender/sets/*.py`): простые матовые формы, никаких скачанных паков
  (`assets3d/` удалён по просьбе пользователя, не предлагать без прямой просьбы).
- **Светлые сцены, минимум теней**: `lib.camera_fill()`, экспозиция +0.35…0.6, туман только мешем `lib.fog_box`.
  Атмосфера через тёплое вечернее небо, контровой свет и дымку, а не темноту.
- Город, а не одна улица: сетка кварталов, площадь с кафе, бульвар, ориентир (пример `fr-klassika/blender/sets/paris.py`).
- **Город реалистичнее** (26.10.2026, следующая задача): коробки с сеткой окон и шары-деревья из
  `posledniy-chelovek-blender` пользователю мало. Делать в коде (паки по-прежнему не предлагать): рельеф фасадов
  (балконы, карнизы, подъезды с козырьками, витрины первых этажей с вывесками), разные материалы (кирпич, штукатурка,
  панель) с износом, крыши с парапетами и надстройками, бордюры и разметка, столбы, светофоры, знаки, урны, скамейки,
  деревья с настоящей кроной, машины разных моделей. Что именно «реалистичнее» — уточнить у пользователя перед работой.
- **Постоянный город «Метрополис»** (26.10.2026): все городские сцены стиля снимаются в одном городе из кода по
  референсам `refs/city-night-water.jpg` и `refs/city-dusk-skyline.jpg` (мегаполис у воды, скайлайн в дымке, неон,
  висячий мост). Логика города — в плане `blender/library/metro_plan.py` (река, набережная с шоссе, сетка проспектов,
  диагональ с площадью экранов, кластеры башен, кирпичные кварталы, парк с озером, два моста, Боро за рекой).
  Снимать сценой `metro.py`: точка съёмки по имени или своя камера по карте, время суток `day/golden/dusk/night`.
  Вблизи камеры город сам добавляет детали улицы. Как подключить и точки съёмки — `projects/metro-city/README.md`.
  Другой город строить, только если сюжет требует другого места (Париж, деревня, Припять и т. п.).
  ~~**Места съёмки каждый раз новые**~~ (26.10.2026, уточнено в тот же день): «точки можешь делать на разных местах
  карты, по своему усмотрению… ролики будут однотипными с одними и теми же местами».
  **Разница и красота, а не запрет мест** (26.10.2026): «точки прям исключать не надо, главное чтобы не было все как с
  конвейра, должна быть разница и красота!», «я говорю глобально, в видосе могут повторяться», «не меняй генератор,
  просто правило». Генератор мест (`metro_spots.py`, журнал `projects/metro-city/spots_used.json`) остаётся как есть,
  а при выборе кадров я держу правило: любое место, в том числе 8 точек v1, можно снять снова под другим углом, в другое
  время суток, другим объективом; внутри ролика возвращаться в то же место можно (тот же сид или своя `cam`); между
  роликами кадры не должны повторять друг друга один в один; из вариантов брать самый красивый.
- Улицы живые, но не перегруженные: машины, люди (`people2.py`: колени, ботинки, кисти, волосы, шаг без проскальзывания,
  сидячие в кафе), фонари, бытовые мелочи. На фоне признаки цивилизации (`civ.py`).
- Люди и конфликты стилизованно, без крови.
- Камера: двумя ключами на сцену (частые ключи дают рывки), объектив около 44 мм, когда нужен «1x»,
  `clip_start` ≥ 0.1 (на облётах 1.0). Не класть плоскости одной высоты внахлёст.

- Главный герой (с 28.10.2026) — модель по фото пользователя `assets3d/people/own/sposobnosti-hero/hero_rig.blend`
  (скелет `HeroRig`, позы `projects/sposobnosti/blender/sets/sila_hero.py`), а не герой из примитивов.
- **Герой живой** (28.10.2026): моргает, водит глазами, дышит, поворачивает голову, в каждой сцене, где видно лицо.
- **Атмосфера** (28.10.2026): благоприятная и интересная, теплее и светлее даже в драматичных сценах.

## Титры, голос, звук, концовка

ссылку не подсвечивать, «Хочешь такие же? Тебе в шапку профиля» не говорить, звать спокойно «переходи в профиль, там новая часть».
Аватар канала — `brand/aipollon-avatar-hermes.png`.
Музыка с 28.10.2026 (версия пользователя `-v4-story`): `ambient-air` под всем роликом, `dark-cinematic` плавно поднимается

Если пользователь просит «оформление как в гибриде», брать разметку титров и звуки из `styles/gibrid/README.md`.

## Два режима рендера

1. **Полный Blender** (по умолчанию для этого стиля): каждая сцена — анимированный клип. ~1–3 с/кадр, минута ролика ≈ 1,5–2 ч.
2. **Быстрый** (раньше назывался «гибридом», пример — v1 `posledniy-chelovek-blender`): из Blender стоп-кадры (`--times … --scale 1.25`)
   с движением камеры в монтаже (`PhotoBG` zoom/pan), анимируются только ключевые «живые» планы. ~15 мин против ~45.
   Предлагать, когда важна скорость.

## Порядок

1. `bash styles/01-klassika/blender-kit/new_blender_project.sh <id>` (или копия `fr-klassika/` для городских сцен с новыми людьми).
2. Факты → сценарий → `script_lint.py` → голос (2 дубля на секцию, Whisper) → `words.json`.
3. `build_timeline.py` → `blender/shots.json` → сцены `blender/sets/<set>.py`.
4. Стоп-кадры `tools/stills.sh` и контактный лист, смотреть самому.
5. Задачи в `jobs/queue/` (пользователь запускает `START_WORKER.bat`), рендер `mkrender.sh`, клипы `-bf 0 -g 30 -keyint_min 30`.
6. `mix.py` → `build_spec.py` → `render.py` → `qa.py` → 20+ кадров из готового MP4.
7. Выдача отдельным файлом с новой версией.

## Чего не делать
- Blender 5.x (30.10.2026): не писать видео через `image_settings.file_format = 'FFMPEG'` без
  `image_settings.media_type = 'VIDEO'`. В 5.2.3 иначе ни один клип не пишется. Исправлено во всех `build_pc.py`.
- Не включать клипы пака LowPolyShorts (Run, FastNod …) на друзьях после `cast.load` (30.10.2026). Кости
  переименованы, поэтому руки и ноги остаются в T-позе. Друзей двигать позами `sila_hero.py` (`key_pose`, `walk`),
  смех — `akad_e3.laugh()`.
- Не закрывать главное событие кадра облаком пыли или дыма: голем в пыли не читался (серия 3 «Академии», 30.10.2026).
