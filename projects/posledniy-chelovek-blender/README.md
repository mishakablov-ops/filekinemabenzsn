- **Стиль:** Блендер, быстрый режим (15 стоп-кадров Blender с наездом и панорамой в монтаже + 4 анимированных клипа)
- **Длительность:** 64,6 с, 20 сцен · **Голос:** тот же, что в `posledniy-chelovek` (Gemini 3.1 Flash TTS «Algenib»)
- **Статус:** выдан 26.10.2026 (`posledniy-chelovek-blender.mp4`: общая папка проекта `aipollon/posledniy-chelovek-blender/`, на ПК — `output/`)

  [`posledniy-chelovek`](../posledniy-chelovek/README.md) (стиль «Гибрид»), но картинка — 3D-сцены Blender в
  реальных цветах. Пользователь выбрал «Быстрый режим».
- **Факты и источники:** те же, что в `posledniy-chelovek` (сценарий, голос и титры не менялись).

## Как собрать

1. `python3 projects/posledniy-chelovek-blender/tools/build_timeline.py` → `blender/shots.json` (длительности и события
   по словам `words.json`).
2. На ПК (воркер `START_WORKER.bat`): `blender -b --factory-startup --python blender/build_pc.py -- --shot <id> --still DIR --scale 1.25`
   для кадров, `--mp4 FILE --scale 1.0 --fps 30 --samples 24` для клипов (сразу H.264 без кадров на диске, ~10 мин на 4 клипа).
   Задачи 320–324 — в `jobs/`.
3. Кадры в `kinema/skills/reel-studio/engine/public/projects/posledniy-chelovek-blender/stills/`, клипы — в `clips/`.
4. `python -I projects/posledniy-chelovek-blender/engine/storyboard.py` → `spec.json`, затем
   `REMOTION_GL=swangle python -I kinema/skills/reel-studio/scripts/render.py posledniy-chelovek-blender --concurrency 4`.

## Структура

```
posledniy-chelovek-blender/
  README.md, cover.jpg (обложка 540×720 для сетки профиля)
  blender/  build_pc.py (вход), shots.json, sets/: pcommon.py (небо, фасады, герой, машины, волки), pcity.py (улицы,
            город с высоты, заправка, Припять), pearth.py (Земля ночью), prooms.py (кафе, ТЭЦ, магазин, квартира, прихожая)
  engine/   storyboard.py → spec.json, words.json (тот же голос)
  tools/    build_timeline.py
  jobs/     задачи воркера 320–324
  qa/       qa.md
```

Нужны с ПК: `lib.py`, `people2.py`, `spacekit.py`, `planet.py`, `city.py`, `civ.py` из `blender/kit` и `blender/library`
(копируются плоско рядом), текстуры NASA берутся из `kosmos-dlya-vseh/blender/tex/nasa` (второй копии нет).
