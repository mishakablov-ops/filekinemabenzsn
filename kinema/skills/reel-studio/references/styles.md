## Taste rules (the user's standing preferences)
- Prefer **dusk / ember / sand / blaze**. Dark, muted, beige → orange. No pure white surfaces; light = beige.
- Few colours per scene, flat fills. Gradients only as subtle light (WarmGlow) — never rainbow meshes.
- 3D kit palettes (`Room3D`, `Street3D`, `Scene3D`) are dark pastel by design: `dusk`, `evening`, `night`, `sand`.
- One accent colour per frame. Red/green only for meaning (bad/good).

## Fonts (all local, Cyrillic)
