## Новый стиль

1. `cp -r styles/_template styles/<NN>-<название>` и заполнить README по шаблону.
2. Превью (`preview.jpg`, 1–3 кадра) положить рядом.
3. Строку — в таблицу выше. Скилл для вызова — `skills/<название>/SKILL.md`, если пользователь хочет отдельную команду.

## Заморозка

Когда пользователь утверждает стиль, в его README пишем дату и образец, а в git ставим тег
`style-<название>-ГГГГ-ММ-ДД` — к этому состоянию всегда можно вернуться (`git checkout <тег> -- blender/kit`).
Копию кита внутрь стиля больше не кладём: это дублирование, историю хранит git.
