## Как добавлять

1. Модуль, который пригодится в других роликах, — копия сюда (имя без номера версии; новая несовместимая версия — `<имя>3.py`).
2. Строка в таблицу: что строит, зависимости, из какого ролика, дата.
3. Если есть удачный кадр — `previews/<модуль>.jpg`.
