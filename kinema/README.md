# KINEMA — движок для 3D-роликов

Папка, в которой ИИ-агент сам делает вертикальные ролики 9:16 для Reels, Shorts и TikTok:
сценарий, живой голос, субтитры точно в слово, 3D-сцены, звук и музыка, фирменная концовка с вашим профилем.
Результат — готовый MP4 1080×1920, 60 fps, проверенный перед выдачей.

Работает с **Claude Code**, **Codex** и другими агентами, которые умеют работать с папкой (Cursor и т. п.).

## Как начать

1. Распакуйте архив в любую папку.
2. Откройте эту папку в агенте как рабочую:
   - **Claude** — приложение Claude, вкладка Code → выбрать папку (или `claude` в терминале из этой папки);
   - **Codex** — приложение или `codex` в терминале из этой папки.
3. Напишите агенту: **«установи и настрой»**. Он поставит всё нужное и спросит:
   - токен Replicate для голоса (обязательно);
   - ключи Fish Audio и ElevenLabs (по желанию);
   - ваш канал — имя, ник, описание, ссылку и аватарку для финальной заставки.
4. Дальше просто: **«сделай ролик про …»**.

Ключ надёжнее ввести самому: `python skills/reel-studio/scripts/setup.py` в терминале из этой папки — он вводится скрыто.
Можно поставить и без агента: Windows — `powershell -ExecutionPolicy Bypass -File install.ps1`, macOS — `bash install.sh`.

## Что умеет

- **Форматы:** объяснялка с голосом, история от первого лица, промо под музыку, **хоррор-сериалы в стиле PS1 + VHS на 1,5–2 минуты**.
- **Голос:** Gemini 3.1 Flash TTS («Algenib») через Replicate; также Fish Audio, ElevenLabs, ваша запись или бесплатный голос.
- **3D:** MacBook и iPhone с живыми экранами, кофейня, библиотека, кухня, домик с камином, офис, убежище, улицы, город, глобус; герой в белой кепке; камера от первого лица.
- **Хоррор-кит (новое):** лоуполи-модели и пиксельная картинка как в старых играх PS1, плёнка VHS (▶ PLAY или ● REC видеокамеры), пиксельные VHS-субтитры с плашками; хрущёвка — подъезд на любое число этажей, дом снаружи днём и ночью, квартира, чердачный люк, почтовые ящики, прихожая с глазком.
- **Свои персонажи и анимация:** персонаж с нуля по описанию (картинка → 3D → скелет в Blender), позы и походка без Mixamo, руки от первого лица, которые берут, держат и переворачивают предметы.
- **Два готовых хоррор-ролика с исходниками:** «Подъезд» (1:57) и «Сосед с шестого этажа» (1:45) — рендерятся сразу и служат шаблоном для своих серий.
- **90+ анимированных блоков:** чаты с ИИ, уведомления, таймлайн, графики, счётчики, чек-листы, профиль TikTok (с новой плиткой «ЧАСТЬ 2» для сериалов).
- **Звук:** пак интерфейсных звуков, кинематографичные удары, 8 музыкальных подложек; свой пак — одной командой.
- **Проверка качества:** наложения, столкновения в 3D, камера внутри объектов, слишком быстрые склейки, громкость −14 LUFS; быстрый просмотр отдельных кадров.
- **Лимит трат:** генерация через Replicate не тратит больше $3 за один ролик без вашего разрешения.

## Что нужно

| | |
|---|---|
| Агент | Claude Code или Codex (подписка у их владельцев) |
| Компьютер | Windows 10/11 или macOS |
| Python | 3.10+ — https://www.python.org |
| Node.js | 18+ (LTS) — https://nodejs.org |
| ffmpeg | Windows: `winget install Gyan.FFmpeg`, macOS: `brew install ffmpeg` |
| Место | ~3 ГБ |
| Replicate | токен для голоса, оплата по факту — https://replicate.com/account/api-tokens (голос ролика ≈ $0.3–0.6, свой персонаж ≈ $1.8) |
| Blender | 4.x, по желанию — только чтобы делать своих 3D-персонажей: https://www.blender.org |

## Где что лежит

- `AGENTS.md`, `CLAUDE.md` — инструкции для агента (их читают Codex, Claude Code и другие)
- `skills/reel-studio` — алгоритм, движок, звуки, музыка, 3D-модели, примеры; готовые ролики — в `skills/reel-studio/engine/out/`
- `skills/reel-script`, `skills/reel-qa`, `skills/reel-analyze` — сценарии, проверка качества, разбор референсов

## Безопасность

Ключи хранятся только у вас в `skills/reel-studio/.secrets.env` и никогда не выводятся на экран. Не отправляйте этот файл никому.

## Лицензии сторонних компонентов

- Движок рендера Remotion бесплатен для частных лиц и компаний до 3 человек; компаниям крупнее нужна лицензия: https://remotion.dev/license
- Голоса генерируются сервисами Replicate (Google Gemini TTS), Fish Audio, ElevenLabs по их условиям использования.
- Руки от первого лица (`engine/public/models/fp_arms.glb`) — «Fps arms» by DJMaesen, Sketchfab, CC BY 4.0, изменены. Если они видны в ролике, добавьте в описание: `3D: "Fps arms" by DJMaesen (Sketchfab), CC BY 4.0, modified.`
- Звуки для хоррор-примеров в архив не входят: положите свои по списку `SOUNDS.md` в папке примера (бесплатные — pixabay.com/sound-effects, freesound.org с CC0). Без них примеры тоже рендерятся.
