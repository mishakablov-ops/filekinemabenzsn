# Серия 3 · «Ноль» (~65 с)

**Логлайн:** герой, который остановил ураган, идёт в школу, где у всех силы, а рядом с ним они гаснут. Его травят.
**Новые:** Денис (сила десятерых); в финале девочка, на которую его ноль не действует.
**Клиффхэнгер:** время остановилось, двигаются только он и незнакомая девочка.

## Текст

```
# --- 1. Хук
%slam Я остановил ==ураган.==
А через неделю // мне пришлось идти в [школу.]

# --- 2. Школа сил
В нашей школе теперь // всё ==по-другому.==
Учительница читает мысли, // списать ~~невозможно.~~
Пацаны телепортируются // с контрольной [в столовую.]
Но стоит мне // зайти в класс...
%slam ...и все силы // ==гаснут.==

# --- 3. Ноль
Меня прозвали ==Нулём.==
Со мной не садятся. // Меня удалили из [чата.]
Денис, у которого сила // ==десятерых,== прижал меня к шкафчику.
А потом его рука // просто *опустилась.*
«Ты труп, Ноль», // сказал он [тихо.]

# --- 4. Столовая
На большой перемене // в столовой что-то ==щёлкнуло.==
Сок завис // в воздухе.
Люди застыли // на полуслове.
Время ==остановилось.==

# --- 5. Клиффхэнгер
Все замерли. // Кроме меня.
И девочки // за последним [столом.]
Она смотрела прямо на меня // и *улыбалась.*
Рядом со мной гаснут все силы. // Но не ==её.==
Следующая серия // уже в ==профиле.==
```
