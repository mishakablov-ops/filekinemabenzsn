# Серия 7 · «Облава» (~65 с, экшен)

**Логлайн:** бой и побег из планетария. Герой становится щитом: силы бойцов Службы гаснут рядом с ним. Побег по
тоннелю метро. Ася жертвует собой, чтобы он успел в поезд.
**Клиффхэнгер:** утром его лицо на всех экранах: «Нулевой опасен. Объявлен в розыск».

## Текст

```
# --- 1. Хук
%slam Нас ==окружили.==

# --- 2. Бой в куполе
У бойцов Службы // тоже есть [силы.]
Щиты. // Захваты. // Прыжки ==сквозь стены.==
Но в моих семи метрах // их силы ==гасли.==
Я стал // нашим [щитом.]

# --- 3. Побег
Ключ открыла люк // в полу.
Мы прыгнули // в старый тоннель ==метро.==
А навстречу нам // шёл [поезд.]
Ася остановила время. // Десять секунд. // Мы успели ==запрыгнуть.==

# --- 4. Ася
Но на платформе // осталась ==она.==
Её держали трое. // Она могла [уйти.]
Вместо этого // она остановила время ==ещё раз...==
и втолкнула меня // в закрывающиеся *двери.*

# --- 5. Клиффхэнгер
Утром моё лицо // было на всех [экранах.]
«Нулевой опасен. // Объявлен в ==розыск.==»
Город, где у каждого суперсила, // начал на меня ==охоту.==
Следующая серия // уже в ==профиле.==
```
