# Шрифты

`nunito-{cyrillic,latin}-{700,900}.ttf` — Nunito (Google Fonts), подмножества кириллицы и латиницы, начертания 700 и 900.
Авторы: Vernon Adams, Cyreal, Jacques Le Bailly, Manvel Shmavonyan, Alexei Vanyashin.
Лицензия: SIL Open Font License 1.1 (https://openfontlicense.org) — можно использовать в роликах и распространять
вместе с кодом; продавать сам шрифт отдельно нельзя.
Используют: `tools/assemble_v5.py`, `tools/cover_v5.py`, `tools/neon.py` (путь — папка скрипта или `FONT_DIR`).
