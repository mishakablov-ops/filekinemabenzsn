# Серия 14 · «Тишина» (~65 с)

**Логлайн:** герой один приходит на телебашню. Орлова — тоже Первая, её сила «приказ» не действует на Первых,
поэтому ей нужна машина. Сделка: мама в обмен на то, что он сядет в кресло. Машина усиливает радиус в тысячу раз,
и волна тишины идёт по планете.
**Клиффхэнгер:** 03:16:59. «Орлова не знала одного. Я умею не только забирать. Я умею отдавать».

## Текст

```
# --- 1. Хук
%slam Я пришёл ==один.==

# --- 2. Орлова
«Тишину» построили // на [телебашне.]
Орлова ждала // на самом верху.
«Я тоже Первая, — сказала она. —
Моя сила — // ==приказ.==
Только на Первых // она ~~не действует.~~»

# --- 3. Сделка
«Сядь в кресло — // и мама [свободна.]»
Машина усилит твой радиус // в ==тысячу раз.==
Силы погаснут // у всего [мира.]
Кроме моих ==людей.==
И я // ==сел.==

# --- 4. Волна
Круг пошёл // по городу.
Летуны мягко опускались // на ==землю.==
Машина бабушки // встала на [асфальт.]
Огонь в ладонях Гоши // ==погас.==
Тишина накрыла // ==полмира.==

# --- 5. Клиффхэнгер
Три шестнадцать. // Пятьдесят [девять.]
Орлова не знала // одного.
Я умею не только // ==забирать.==
Я умею *отдавать.*
Следующая серия // уже в ==профиле.==
```
