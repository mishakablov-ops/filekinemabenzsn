# Серия 12 · «Тот, кто загадал» (~65 с, главный поворот сезона)

**Логлайн:** Тимофей видит, что человек загадал в 03:17. Каждая сила — это желание. Денис хотел защищать сестру,
бабушка — снова быть нужной. А силы всем раздал герой: той ночью он отдал всё, что копил десять лет.
**Клиффхэнгер:** Орлова выпускает Бурана, человека-погоду из серии 2. К нему нельзя подойти: он просто держится далеко.

## Текст

```
# --- 1. Хук
%slam Тимофей видит ==желания.==
То, что человек загадал // в ночь на [три семнадцать.]

# --- 2. Желания
Денис хотел // защищать младшую ==сестру.==
Бабушка у подъезда // хотела снова быть [нужной.]
Курьер — // хоть раз нигде не ==опоздать.==
Каждая сила — // это ==желание.==

# --- 3. Ночь
«А ты, — сказал Тимофей, — // загадал // для ==всех.==»
И я вспомнил ту ночь.
Я смотрел на город // и думал:
«Пусть у каждого будет то, // что ему ==нужно.==
А мне // ничего не [надо.]»

# --- 4. Правда
Всё, что я копил // десять лет, // я ==отдал.==
Каждому — // по [способности.]
Это сделал // ==я.==

# --- 5. Клиффхэнгер
И тут // небо ==потемнело.==
Орлова выпустила // [Бурана.]
Того, кто управляет // ==погодой.==
И он знал, // как меня победить:
просто // ==не подходить.==
Следующая серия // уже в ==профиле.==
```
