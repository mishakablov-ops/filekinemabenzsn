## Продвижение

1. **Точка Б:** написать «чек» в комментах.
2. **Тип виральности:** лайфхак + «до и после» (длинный чек вечеров → короткий «один раз»).
3. **Хук 0–3 с:** «Посчитаем, сколько вечеров съедает канал без лица», первый кадр движется: из принтера ползёт чек до пола.
4. **Эмоции:** 0–8 с любопытство (сколько?) → 8–12 с норадреналин (30 вечеров, ночь за монтажом) → 12–20 с эндорфин
   (одна фраза, ролик сам, прогулка) → 20–28 с «это и мне подходит» (любая лента, любая тема) → 28–34 с облегчение
   (короткий чек, один раз) → 34–37 с слово.
5. **Что сохранят:** карточка «Сам: 30 вечеров в месяц за монтажом / С KINEMA: одна фраза — ролик для любой ленты».
6. **Что перешлют:** «жиза» — ночь за монтажом одного ролика; другу, который ведёт канал или своё дело.
7. **Повод для комментария:** «а у меня уходит…» — у зрителя своё число вечеров; «а для моей темы подойдёт?».
8. **Самопроверка:** досмотрел бы — да (интрига «сколько?»); сохранил бы — да (сравнение); переслал бы — да;
   подписался бы — скорее да.
