# Стиль «Гибрид» (утверждён пользователем 23.10.2026)

> Пути в этом файле — как на ПК (`aipollon claude/…`). В репозитории: `AIpollon-Reel-Studio/skills/reel-studio` → `kinema/skills/reel-studio`, `blender-kit` → `blender/kit`, `references/` → `knowledge/rules/`, проекты → `projects/<id>/`. Полная таблица — в корневом `README.md`.

Эталоны, которые прислал пользователь: `coffee-agent.mp4` (38 с) и `выживач после бомбы.mp4` (87 с).
Оба собраны движком Reel Studio (Remotion + three.js), исходники на ПК:
`AIpollon-Reel-Studio/skills/reel-studio/examples/coffee-agent/` и `.../examples/nuclear-survival/`
(`script.md`, `spec.json`, `words.json`, раскадровка `storyboard*.py`, голос `voice_*sections.py`).
**Новый ролик в этом стиле начинать с копии одного из этих примеров**, а не с нуля.

«Гибрид» = мультяшные 3D-сцены из кода (three.js) + 2D-инфографика и интерфейсы поверх + редакционные
кинетические титры. Blender в этом стиле не нужен, рендер идёт целиком в Remotion.

## 1. Картинка

- Стиль движка `dusk`: тёплый графит `#2A2622`, бежевый текст `#EDE3D4`, акцент терракота/оранжевый `#E08A55`
  (на плашках `#D9732F`). Никакого чистого белого, ни одного радужного градиента. Сцены тёмные, тёплые, приглушённые,
  но объекты читаются: мягкий тёплый свет ламп, окна с закатным светом, лёгкая дымка.
- 3D: матовый low-poly «пластилин» без текстур. Люди — простые фигурки (голова-шар, цилиндрические руки, без
  пальцев), герой ролика всегда один: парень в белой кепке и оранжевой кофте (`look: {hero: true}`),
  костюм выживальщика `suit: true` с надеванием по словам (`suitAt`).
- Места: `Room3D` (cafe, office, kitchen, basement, cabin, library), `Street3D` (`evening`, `abandoned`),
  `Blast3D`, `Bars3D` (объёмные столбики-диаграммы), `MacBook`/`Laptop3D` с живым экраном,
  `IPhone17` (`flip`/`spin`, на экране LockScreen, уведомления, `TikTokProfile`).
- Камера **всегда движется**: медленный наезд/дрейф двумя ключами за сцену, иногда вид от первого лица
  (`fpv*`, голова без рук), съёмка «по плечо» героя, крупные планы предметов (кофемашина, бойлер, аптечка, радио).
- Интерфейсные вставки на тёмных скруглённых плашках: чек-листы с оранжевыми галочками, появляющимися по словам
  («Агент собирает: Сценарий / Голос / Монтаж», «Костюм: Дождевик / Перчатки…»), карточки уведомлений с буквой-иконкой
  («Б Бронь · Столик на 4»), стрелочные списки «→ Мыло → Шампунь → ~~Бальзам~~», окно чата агента «✳ Доброе утро».
- Большие цифры-счётчики по центру: «0 секунд до волны», «200 литров в бойлере», «5 дней в подвале»,
  «90 %» оранжевым на почти чёрном фоне с тёплым свечением.
- Глубина резкости: при смене плана фон уходит в сильное размытие, на крупных планах размыт задний план.

## 2. Титры (главная фишка стиля)

Режим `captions: {mode: "editorial", pos: "top", uppercase: true}`, верхняя треть кадра, по центру.
Каждая строка сценария = карточка из двух ярусов (`lead // punch`):

- **lead** — маленькая серая строка (нижний регистр, ~46 px): завязка фразы. «Днём у меня кофейня:»
- **punch** — крупно, жирно, ЗАГЛАВНЫМИ (Inter Tight 800): удар. «ГОСТИ, ЗАКАЗЫ, ПОСТАВКИ.»
- Слова появляются **по одному ровно со словом голоса**, из размытия в резкость (0,3 с).
- Смена карточки: старая уходит в размытие, новая проявляется.
- Ровно **один акцент на карточку**, на слове со смыслом (число, предмет, эмоция):
  - `==слово==` — оранжевая плашка с тёмным текстом («6 ЧАСОВ», «В ДЕСЯТЬ РАЗ», «В ШАПКУ ПРОФИЛЯ»);
  - `[слово]` — оранжевый цвет без плашки («ПОСТАВКИ», «ВСПЫШКА», «НИКОГО»);
  - `*слово*` — курсив с засечками Playfair, строчными: эмоция, мягкость, ирония
    («*ради*», «*звуки*», «*варил кофе*», «*секунды*», «*радиоактивная*», «*остановился*», «*Тишина.*»);
  - `~~слово~~` — красная линия перечёркивает отрицание сразу после слова («ДЕЛО ~~НЕ~~ РАСТЁТ», «~~НЕ~~ ПЕЙ», «~~НЕЛЬЗЯ~~»).
- Хук и пики делать режимом `%slam` по центру гигантскими буквами («6 ЧАСОВ / *ради* / ==40 СЕКУНД==», «ДВЕРЬ.», «ГРОХОТ.»).
- Лимиты: punch ≤ 34 символов, lead ≤ 46, хук ≤ 7 слов. Титры не закрывают лица, руки и экраны (3D-сцена кадрируется ниже).

## 3. Подача и сценарий

- Короткие рубленые фразы по 2–6 слов, у каждой ритм «завязка → удар». Почти без тире.
- Хук за 3 секунды: конкретная цифра или событие («Я монтировал один ролик 6 часов. Ради 40 секунд.»,
  «Обычный вечер. И вдруг вспышка.»).
- Две формулы:
  - **история от первого лица** (кофейня, ~40 с): боль → поворот («однажды я просто написал агенту») → как теперь → подводка;
  - **«ты»-инструкция** (выживание, ~85 с): катастрофа во 2-м лице → по шагам, что делать руками, с реальными цифрами
    и источниками (МЧС, Ready.gov) → развязка с атмосферой («Тишина. Ни машин. Ни людей. Никого. Город просто остановился.»).
- Факт или цифра каждые 2–3 фразы, все цифры реальные.
- Темп голоса ≈ 2,3–2,5 слова/с, без длинных пауз. Сцена меняется каждые 2,5–3,5 с
  (11 сцен на 36 с, 30 сцен на 85 с), каждая смена на слово-якорь (`"at": "@слово"`).
- Концовка одна и та же: «Кстати, этот ролик тоже собрал агент / это видео сделала ==нейросеть==.
  Хочешь так же / делать такие же [в два клика?] Тебе ==в шапку профиля.==»
  Белый `IPhone17` поднимается задней крышкой, разворачивается к экрану с профилем TikTok aipollon,
  оранжевая рамка подсвечивает описание и ссылку. Фон — размытая сцена ролика.

## 4. Переходы

`push`, `zoom`, `blur` основные; `whip` для резкой смены места; `flash` на взрыве/вспышке; `fade`/`dip` для паузы
и смены времени («Дверь открывается» → `dip` → улица). Жёстких склеек мало, всё мягко через размытие.

## 5. Звук

- Голос: Gemini 3.1 Flash TTS «Algenib», мужской, тёплый, живой (по секциям, 2 дубля). В драме допустимы режиссёрские
  пометки `((urgent))`, `((sad, slow))`, `((whispering))` только на одно слово-пик.
- Музыка тихой подложкой всё видео: `lofi-warm` для тёплых историй, `dark-cinematic` для драмы; громкость 0,10–0,14,
  приглушение под голосом 0,45. Мастер −14 LUFS.
- `autoSfx: false`. Ручные звуки из пака пользователя `pk-*` **почти на каждое ключевое слово**: щелчок на пункте списка,
  поп на появлении плашки, уведомление на «гостях» и «профиле», `pk-result-failure` на отрицании, шиммер на «Кстати».
  Кинематографичные звуки только на сюжетные события (`nuke-boom`, `door-heavy-close`, `shockwave-hit`, `geiger-low`, сирена).
  Один и тот же звук два раза подряд не ставить.

## 6. Как делать

1. `cp -r examples/<coffee-agent|nuclear-survival> engine/public/projects/<id>`, поменять `id` и пути.
2. Сценарий в разметке выше → `script_lint.py` до `LINT OK`.
3. Голос по `voice_sections.py` → `tts.py --engine audio --tighten 0.25` → `words.json`.
4. Раскадровка `storyboard.py` → `spec.json` (сцены на якорях-словах, камера двумя ключами).
5. `stills.mjs --qa` по каждой сцене, затем `render.py <id>`, `qa.py`, 20+ кадров из готового MP4.
6. Выдача в `output/<id>.mp4`, новые версии отдельными файлами.

## 7. Концовка (пожелание пользователя 23.10.2026)

- В сетке профиля TikTok **обложки разных настоящих роликов канала** (`brand/tiles/cover-*.jpg`, кадр 3:4 из готового MP4,
  540×720, новый ролик первым и закреплён). Выдуманных обложек не делать.
- **Цвет айфона под тему ролика**: у `IPhone17` (и любого `Model3D`) параметр `color` перекрашивает корпус.

## 8. Реалистичная картинка (ролик «Один язык», 23.10.2026)

- Тема `fresh`: тёмный фон, белые титры внизу (`captions.mode "pill"`), произносимое слово на жёлтой плашке.
- Настоящие модели Poly Haven (CC0) лежат в `engine/public/models/ph/<id>/<id>.gltf`; в `Scene3D` это объект
  `{type: "model", src, pos, rotY, h?, s?, tint?}` (размеры в реальных метрах). Палитра `look: "real"` для стен, пола и людей.
- Важно: при рендере ThreeCanvas рисует кадр только при смене кадра (frameloop "never"), поэтому `Scene3D`
  монтирует канвас только после загрузки всех glTF (`useGltfs` возвращает null, пока грузит). Иначе модели не видны.
- Земля целиком с небом вокруг: `Globe3D look "earth"` поверх `Sky`, `dist` 6.5–8.5 (радиус 1, fov 30). Подписи
  гасятся у правого края кадра.
- Читаемость поверх 3D: `Kicker {size: 46, solid: true}`, `Bubble {size: 46}`, у подписей `Scene3D.labels` есть `size`.
- Кадр 9:16 узкий: для групп людей и мебели брать fov 46–50 и камеру на 4–6 м; проверять каждую сцену на листе кадров.
