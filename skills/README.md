# Скиллы

Тексты скиллов, которыми пользователь вызывает стиль ролика. Здесь лежит рабочая версия знаний; в аккаунте
claude.ai скилл может быть короче и ссылаться сюда.

| скилл | файл | стиль | описание стиля |
|---|---|---|---|
| `/gibrid` | [`gibrid/SKILL.md`](gibrid/SKILL.md) | «Гибрид» | [`styles/gibrid/README.md`](../styles/gibrid/README.md) |
| `/blender` | [`blender/SKILL.md`](blender/SKILL.md) | «Блендер» | [`styles/blender/README.md`](../styles/blender/README.md) |

Правило: SKILL.md — это **порядок действий**, а как ролик должен выглядеть и звучать — в `styles/<стиль>/README.md`
и `knowledge/rules/`. Меняется процесс → правим SKILL.md, меняется картинка → правим стиль.
