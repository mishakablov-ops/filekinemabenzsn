# Библиотека сцен и моделей из кода

Модули Blender (Python, `bpy`), которые строят модели и анимацию кодом. Импортируют `lib` из `blender/kit/blender/`
и друг друга по имени, поэтому в проект их **копируют плоско** в `blender/sets/`.

| модуль | что строит | зависит от | откуда | дата |
|---|---|---|---|---|
| `people2.py` | люди нового качества: колени, ботинки, кисти, волосы; шаг под скорость без проскальзывания; сидячие и стоячие позы | `lib` | fr-klassika → kosmos-dlya-vseh | 24.10.2026 |
| `paris.py` | город, а не улица: сетка кварталов с мансардами, площадь с кафе, бульвар, Эйфелева башня | `lib`, `civ`, `city`, `people2` | fr-klassika | 22.10.2026 |
| `spacekit.py` | космос в реальных цветах: ракеты, выхлоп, реголит, планеты, поворот глобуса к точке | `lib`, numpy | kosmos-dlya-vseh | 24.10.2026 |
| `planet.py` | планета/Земля | `lib`, `spacekit` | kosmos-dlya-vseh | 24.10.2026 |
| `orbit.py` | орбита, станция, спутники | `lib`, `spacekit` | kosmos-dlya-vseh | 24.10.2026 |

Базовые сцены (globe, wall, checkpoint, passport, city, village, military, tabletop, pumpjack, civ) лежат в `blender/kit/blender/sets/`.

## Как добавлять

1. Модуль, который пригодится в других роликах, — копия сюда (имя без номера версии; новая несовместимая версия — `<имя>3.py`).
2. Строка в таблицу: что строит, зависимости, из какого ролика, дата.
3. Если есть удачный кадр — `previews/<модуль>.jpg`.
