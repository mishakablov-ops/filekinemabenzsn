# «Сосед с шестого этажа», серия 1 (~2 мин). Лавкрафтовский ужас, загадка. Голос: Gemini 3.1 Flash TTS · Algenib.
# Рассказывает жилец пятого этажа. Приёмы: открытая петля в хуке, правило трёх (шаги, мебель, плач),
# конкретика (03:12, 3 секунды, 1974, ящик 24), статичная ночная камера, улика-загадка (24 ящика на 20 квартир),
# отказ от разрядки (он не опустил руку), переосмысление в конце (на фото шесть этажей и человек, похожий на меня),
# финал на пике (лестница идёт выше пятого).

# --- 1. Хук
Я живу на пятом этаже // ==пятиэтажки.==
Две недели каждую ночь // надо мной *двигают мебель.*
Но выше меня // ==никого нет.==

# --- 2. Правило трёх
Сначала шаги. // ==Босиком.==
Потом скрежет. // Как будто тащат *шкаф.*
А в ночь на субботу // ==детский плач.==

# --- 3. Над нами только крыша
Я позвонил в управляющую. // Мне сказали:
над вами только // ==крыша.==
Люк на чердак // заварен с {1998|девяносто восьмого} *года.*
Я поднялся проверить. // Сварка ржавая.
А на крышке // ==свежие царапины.==
*Изнутри.*

# --- 4. Камера
Тогда я поставил камеру. // ==Ночь первая.==
Три двенадцать. // Шаги начались.
На видео я в комнате один. // А на звуке // нас ==двое.==
Шаги повторяют // каждый *мой шаг.*
С задержкой // в ==три секунды.==
Я остановился. // Раз. Два. Три.
Наверху // тоже *остановились.*
Я поднял руку. // Над потолком // ==скрип.==
Я опустил руку. // А он // ==не опустил.==
Утром на потолке // над кроватью // проступило ==пятно.==
По форме // как *ладонь.*

# --- 5. Ящик 24
Утром в подъезде // был открыт ==почтовый ящик.==
Номер {24|двадцать четыре.} // А квартир в доме // ==двадцать.==
Внутри старая *фотография.*
Мой дом. // {1974|Семьдесят четвёртый} год.
Я посчитал этажи. // ==Шесть.==
В окне шестого // стоит человек.
Он // *похож на меня.*
На обороте ручкой: // «Не позволяйте жильцу сверху
узнать, что этаж ==исчез.==»
Соседка снизу // посмотрела на фото
и сказала, что я // ==здесь не живу.==

# --- 6. Финал на пике
Этой ночью шаги // спустились к моей ==двери.==
Я посмотрел в глазок. // Лестница // шла ==выше пятого.==
А наверху // горел *свет.*

# --- 7. Подводка
Продолжение // смотри в *профиле.*
