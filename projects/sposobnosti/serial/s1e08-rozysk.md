# Серия 8 · «Розыск» (~65 с, экшен)

**Логлайн:** героя ищет весь город. Телепаты не слышат его мысли, но Служба находит его по «пятну тишины» на карте.
Погоня по рынку, крышам и мосту. Из реки его вытаскивает Денис.
**Клиффхэнгер:** Смотритель показывает фото: героя в шесть лет держала Служба, «Объект Ноль».

## Текст

```
# --- 1. Хук
%slam Восемь миллиардов суперлюдей // ищут ==одного.==

# --- 2. Охота
Летуны прочёсывают ==крыши.==
Телепаты слушают // мысли всего [города.]
А меня не услышать. // Рядом со мной мысли ==молчат.==

# --- 3. Тишина
Но Служба // оказалась ==умнее.==
На карте мыслей // по городу ползло // ==пятно тишины.==
Меня искали // ~~не по мыслям.~~ // По [тишине.]

# --- 4. Погоня
Рынок. // Крыши. // ==Мост.==
Летун спикировал на меня // и рухнул, // влетев в мой [круг.]
Я прыгнул // с моста в ==реку.==

# --- 5. Денис
Из воды меня вытащила рука // толщиной с ==бревно.==
Денис.
«Я тебе должен. // За [площадку.]»

# --- 6. Клиффхэнгер
В его гараже // нас уже ждал ==Смотритель.==
Он протянул мне // старое фото.
Мне на нём шесть. // Я в больничной [рубашке.]
А на табличке: // «Служба. Объект ==Ноль.==»
«Ты у них // уже *был.*»
Следующая серия // уже в ==профиле.==
```
