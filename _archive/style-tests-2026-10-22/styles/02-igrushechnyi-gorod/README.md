# Стиль 2 · Игрушечный город

Чистый «игрушечный» мульт Kenney: гладкие формы, плоские яркие цвета, без текстур, всё как набор игрушек. Готовые города, пригороды, промзоны, дороги, машины, поезда, лодки, мебель, еда, природа. Люди — круглые мини-персонажи (чиби). Сразу собирается живая улица.

Превью: `preview.jpg` в этой папке (если есть).
