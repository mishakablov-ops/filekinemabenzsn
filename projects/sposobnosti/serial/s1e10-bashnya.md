# Серия 10 · «Башня» (~65 с, штурм)

**Логлайн:** команда идёт за Асей в штаб Службы — башню, которая висит над городом на силе сорока телекинетиков.
План по секундам, штурм, герой идёт по коридору и выключает охрану одним присутствием.
**Клиффхэнгер:** Ася сидит без наручников и говорит: «Зачем ты пришёл? Я здесь сама».

## Текст

```
# --- 1. Хук
%slam Мы идём // за ==Асей.==

# --- 2. Крепость
Штаб Службы — // башня, которая ==висит== в небе.
Её держат // сорок [телекинетиков.]

# --- 3. План
Эхо слышит охрану // на три секунды ==вперёд.==
Ключ открывает // [двери.]
Денис // ==выбивает== те, что не открываются.
А я иду по коридору // и выключаю ==всех.==

# --- 4. Штурм
Охрана прыгала на меня // и падала на пол // ==обычной.==
Сирены. // Красный свет. // Минус седьмой [этаж.]
Ключ открыла // последнюю ==дверь.==

# --- 5. Клиффхэнгер
Ася сидела в кресле. // Без [наручников.]
Она подняла глаза // и сказала:
«Зачем ты пришёл? // Я здесь ==сама.==»
Следующая серия // уже в ==профиле.==
```
