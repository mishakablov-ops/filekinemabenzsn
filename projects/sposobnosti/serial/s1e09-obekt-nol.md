# Серия 9 · «Объект Ноль» (~60 с, флешбэк)

**Логлайн:** Смотритель возвращает герою память. В шесть лет он был в лаборатории Службы вместе с маленькой Асей,
они сбежали, ему стёрли память. Его сила не гасит, а забирает и копит.
**Клиффхэнгер:** в ночь 03:17 кто-то отдал миру все накопленные силы разом, и Орлова знает кто.

## Текст

```
# --- 1. Хук
Смотритель коснулся // моего лба.
%slam И я ==вспомнил.==

# --- 2. Лаборатория
Мне шесть. // Белые стены. // [Стекло.]
Нас было двенадцать. // Дети с ==силами.==
Молодая Орлова // записывала // каждый наш [шаг.]

# --- 3. Ася
На соседней койке // сидела девочка // с ==косичками.==
Она останавливала время, // чтобы мы успевали // доесть [мороженое.]
Это была ==Ася.==

# --- 4. Побег
Однажды ночью // мы ==сбежали.==
Она остановила время. // Я погасил // все ==датчики.==
Потом мне стёрли память.
И десять лет // я думал, // что я ~~особенный~~ самый [обычный.]

# --- 5. Правда
«Ты не гасишь силы, — // сказал Смотритель. —
Ты их ==забираешь.== // И [копишь.]»

# --- 6. Клиффхэнгер
«В ночь на три семнадцать // кто-то силы ==отдал.==
Восемь миллиардов // способностей // [разом.]
И Орлова // знает, *кто.*»
Следующая серия // уже в ==профиле.==
```

> Строка 4: зачёркивание «особенный» оставить титром, голосом читать «что я самый обычный».

## Раскадровка и монтаж

Вся серия, кроме начала и конца, — ПАМЯТЬ: тёплая сепия, зерно, виньетка. Лаборатория не страшная: белая, мягкий
дневной свет, рисунки детей на стекле, игрушки. Тревогу дают звук и музыка, а не мрак.
