## Как собрать

1. `python3 projects/posledniy-chelovek-blender/tools/build_timeline.py` → `blender/shots.json` (длительности и события
   по словам `words.json`).
2. На ПК (воркер `START_WORKER.bat`): `blender -b --factory-startup --python blender/build_pc.py -- --shot <id> --still DIR --scale 1.25`
   для кадров, `--mp4 FILE --scale 1.0 --fps 30 --samples 24` для клипов (сразу H.264 без кадров на диске, ~10 мин на 4 клипа).
   Задачи 320–324 — в `jobs/`.
3. Кадры в `kinema/skills/reel-studio/engine/public/projects/posledniy-chelovek-blender/stills/`, клипы — в `clips/`.
4. `python -I projects/posledniy-chelovek-blender/engine/storyboard.py --quick` → `spec.json` v1, затем
   `REMOTION_GL=swangle python -I kinema/skills/reel-studio/scripts/render.py posledniy-chelovek-blender --concurrency 4`.
5. **v2 (полный режим):** `tools/build_timeline.py` без `--quick` делает все сцены клипами; `tools/mkjob.py bg_327_pcb_v2_clips.ps1
   clip60 1.0 <19 сцен>` → задача воркера (`--mp4 --fps 60 --samples 24`, клипы в `clips_v2/` на ПК, ≈ 51 мин);
   клипы → `engine/public/projects/posledniy-chelovek-blender-v2/clips/` (+ `voice.wav`, `words.json`);
   `storyboard.py` без флага → `spec.json` v2; `render.py posledniy-chelovek-blender-v2`.

```

  README.md (обложка — `kinema/skills/reel-studio/engine/public/brand/tiles/cover-posledniy-chelovek-blender.jpg`)
  blender/  build_pc.py (вход, модули берёт из `blender/library/`), shots.json; модули: pcommon.py (небо, фасады,
            герой, машины, волки), pcity.py (улицы, город с высоты, заправка, Припять), pearth.py (Земля ночью),
            prooms.py (кафе, ТЭЦ, магазин, квартира, прихожая)
  engine/   storyboard.py → spec.json (v1, `--quick`) и spec-v2.json (v2), words.json — из `projects/posledniy-chelovek/engine/` (тот же голос)
  tools/    build_timeline.py (`--quick` = v1), mkjob.py (задачи воркера: still / clip / clip60)
  jobs/     задачи воркера 320–324 (v1), bg_327 (v2)
  qa/       qa.md
```

Нужны с ПК: `lib.py`, `people2.py`, `spacekit.py`, `planet.py`, `city.py`, `civ.py` из `blender/kit` и `blender/library`
(копируются плоско рядом), текстуры NASA берутся из `kosmos-dlya-vseh/blender/tex/nasa` (второй копии нет).
