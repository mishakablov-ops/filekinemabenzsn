- **Стиль:** блендер (тест формата «один персонаж в N стилях»), рендер **в облаке** (Blender 5.2.3 через `pip install bpy`)
- **Длительность:** ~23 с (10 стилей × 2 с + концовка 3 с) · **Голос:** нет (тест), звуки: «поп» на смене стиля, шелест, птички

## Как устроено

Одна сцена из кода (`blender/scene.py`): такса из метаболов (тело, голова и хвост — одно мягкое тело, голова и хвост
на своих пустышках для анимации), полянка с холмами, кустами, цветами, забором, домиками, деревьями, облаками и бабочкой.
Стиль задаётся аргументом: палитра + тип материала.

| стиль | как получается |
|---|---|
| Мягкое 3D | Principled + sheen, Cycles CPU, 28 сэмплов + денойз |
| Плоский мультик, Неон, Чертёж | рендер `flat` (эмиссия, без света) → `tools/post.py` рисует контур по границам цветов |
| Полутон | `flat` + растр точек там, где мягкий рендер темнее (`halftone2`, нужен кадр `soft3d`) |
| 16-бит | `soft3d` → уменьшение до 150 px, палитра 40 цветов, тёмный контур в 1 px |
| Силуэт | эмиссия: собака чёрная, всё остальное бежевое, жетон красный |
| Пластилин ★ | матовый, бамп «вмятины + отпечатки» (Voronoi + Noise), яркая пластилиновая палитра |
| Гжель ★ | белый фарфор с кобальтовыми кольцами (Wave RINGS), глянец + coat, экспозиция −1.3 |
| Low poly 90-х | грубое разрешение метаболов + плоские нормали через True Normal, кусты/кроны децимейтом |

★ — придумано сверх образца.

## Запуск (облако)

```
uv venv -p 3.13 bpyenv && VIRTUAL_ENV=bpyenv uv pip install bpy==5.2.3 pillow
bpyenv/bin/python blender/scene.py soft3d /out/still.png 24 24 540          # стоп-кадр
tools/render_all.sh                                                          # все кадры клипа (15 к/с «на двойках»)
bpyenv/bin/python tools/assemble.py                                          # стили, плашка, концовка, звук → MP4
```

Скорость (4 ядра облака): мягкие стили ≈ 10 с/кадр при 540×960, плоские ≈ 2 с; сборка сцены ≈ 40 с на запуск.
Freestyle не использовать: минуты на кадр. Контуры — обработкой кадра (`post.py`).
