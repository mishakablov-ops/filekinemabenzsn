# Как познакомиться с девушкой (`kak-znakomitsya`)

- **Стиль:** пиксель PIXCINE 9:16 (движок `Wpresser/Algorithm-for-aipollon`, `pixcine/`), формат принятого «Как жить, если ты тупой» v4
- **Голос:** MiniMax speech-2.8-hd «Russian_ReliableMan» ×1.35, озвучка на ПК (`voice_grid.py znakomstva --grid 0.1`), id озвучки `znakomstva`
- **Задача mike (16.11.2026):** «сделай мне ролик в пиксельном стиле, как правильно знакомиться с девушками, видео юморное».
  Тон: добрый юмор, смеёмся над Витьком, а не над девушками; без пошлости. Мат не просили — без мата. Без музыки.
- **Статус:** в работе.

## Продвижение
1. **Точка Б:** досмотреть до правила «просто скажи привет» и переслать другу, который «подкатывает».
2. **Виральность:** юмор + жиза (переписка «Ты ела?» — «Да»), смешной кринж без обиды.
3. **Хук 0–3 с:** «Как познакомиться с девушкой? Витёк прочитал сорок гайдов» + кадр-тизер из финала (Витёк с букетом с клумбы, за ним полицейский).
4. **Эмоции:** провалы Витька подряд (норадреналин) → поворот на лавке, Лиза узнаёт героя «столба» (окситоцин) → правило (серотонин).
5. **Сохранят:** список способов с зачёркиванием и итог «Просто скажи привет».
6. **Перешлют:** переписку «Привет — стёр, Хай — стёр… Ты ела? — Да».
7. **Комментарий:** «а какой подкат худший у вас?» — повод без прямой просьбы.
8. **Самопроверка:** досмотрел бы — да (каждые 8 с новый провал); сохранил бы — да (список); переслал бы — да; подписался бы — да (Витёк сквозной герой канала).

## Концовка (своя тема, не как у «тупого»)
Тема `love`: розовая шапка профиля с сердечками; сердце лайка «разбитое» склеивается и загорается, кнопка подписки в
виде валентинки. Шутки: лайк — «ВИТЬКУ НА ЦВЕТЫ НЕ С КЛУМБЫ», подписка — «ЭТО ТОЖЕ ПОДКАТ, НО РАБОЧИЙ». Голос мягко: «переходи в профиль».
